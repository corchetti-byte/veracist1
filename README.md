# verAcist — PWA integrado

Aplicativo web para Solicitações de Assistência Técnica e Visitas Técnicas vinculadas.

## Teste local
```bash
python3 -m http.server 8080
```
Abra `http://localhost:8080`.

## Observação
Esta versão usa armazenamento local do navegador. Para múltiplos usuários e sincronização, conecte um backend (Supabase/Firebase).
